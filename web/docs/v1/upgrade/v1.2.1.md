# v1.2.1 升级指南

## 重点检查

### 运行环境

- 无新增运行环境要求，最低 PHP 版本仍为 `8.2`

### 简单使用者

- **ThinkPHP 8 用户**：本版本新增框架容器兼容，升级后 `Artful` 会自动探测并复用 `think\Container`，**无需再安装 `hyperf/pimple`**（此前 ThinkPHP 用户需借助它作为兜底容器）
- **hyperf/laravel 用户**：无任何影响，行为与此前一致
- **其它/无框架用户**：仍按文档安装 `hyperf/pimple` 或 `illuminate/container` 即可，无变化

### 自有插件开发者

- 插件、Packer、Direction、Shortcut 相关契约**无任何变更**
- 若你继承或参考 `ContainerServiceProvider` 自定义了服务提供者，注意容器探测分支新增了 `thinkphp`（探测顺序：laravel → hyperf → thinkphp → default），并新增了 PSR-11 适配器 `ThinkPHPContainerAdapter`

## 更改版本号

```bash
composer require yansongda/artful:~1.2.1
```

## BREAKING CHANGES

- 无
