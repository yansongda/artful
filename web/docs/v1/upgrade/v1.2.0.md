# v1.2.0 升级指南

## 重点检查

### 运行环境

- PHP 最低版本由 `8.0` 提升至 **`8.2`**
- 依赖 `yansongda/supports` 升级至 `~4.1.0`（PHP >= 8.2 环境下由 Composer 自动解析安装）

### 简单使用者

本次发布 **artful 自身 API 无任何变更**（`src/` 零改动），但随 `yansongda/supports` 4.1.0 带来以下底层行为变化，若你的代码直接使用了 `Yansongda\Supports\Collection`，请重点检查：

- `Collection::has()`：由「值非 `null` 判断」改为「键存在性判断」—— 键存在但值为 `null` 时，现在返回 `true`（此前返回 `false`）；同时支持传入数组
- `Collection::only()`：键存在但值为 `null` 的项现在会被保留（此前会丢弃）
- `Collection::first()` / `last()`：空集合现在返回 `null`（此前返回 `false`）

::: warning 注意
通过 `$rocket->getPayload()` / `$rocket->getParams()` 获取的即为 `Collection` 实例，若你的业务代码或插件依赖上述旧语义，请逐一核对。
:::

### 自有插件开发者

- 插件相关契约（`PluginInterface`、`PackerInterface`、`DirectionInterface`、`ShortcutInterface` 等）**无任何变更**
- `src/` 零改动，所有插件、Packer、Direction、Shortcut 无需调整

## 更改版本号

```bash
composer require yansongda/artful:~1.2.0
```

## BREAKING CHANGES

- 最低 PHP 版本提升至 `8.2`（PHP 8.0 / 8.1 环境请继续使用 `~1.1.0`）
